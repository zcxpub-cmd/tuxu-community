# 一键制作与日夜外观

## 使用一键生成

1. 在工作台标题下的“创作方式”选择“一键生成”。
2. 导入 DOCX、Markdown、TXT，或粘贴并保存文章。
3. 核对本地文字模型、图片生成服务和导出格式。默认导出可编辑 Word，也可选 Markdown 图片包或 HTML。
4. 点击“一键生成图文文档”，即授权这次自动制作。图序自动分析全文、使用语义推荐画风、由本地模型组织正式画面描述、生成图片，再选用全部有效原图插入并导出新文档。
5. 完成后点击下载；需要修改时，进入人工设置查看图片、图注和插入预览。

每篇最多5张，每个图位仅尝试一次；模型建议超出授权数量会停止，不擅自增加调用。语义分析建议无需插图时，直接导出保留正文的副本。一键模式适用于刚导入、尚未制作的原稿；已有人工方案不会被一键覆盖。默认采用原图，降噪和放大仍可在人工模式选图页按需处理。

## 服务与授权

文章分析和正式画面描述继续由本地 Ollama 完成。图片可使用已连接的 ComfyUI、本机智能体或自备图片 API。原生及通用智能体都必须实际配置并启用；仅有文字聊天能力不等于可以生图。生图计算可能联网、使用账号额度或产生费用；应用不会附带云端密钥。

点击时绑定当前文章、风格、本地文字模型、图片服务及其配置版本、数量与文档格式。后台分析之后不会静默换用其他服务。完整生图文本和执行凭据仍保留在后台，前端展示简短描述与进度。

## 暂停、刷新和人工接管

一键步骤由本地服务持久化执行，网页只读取进度。关闭网页不会重复提交；重新打开可从作品记录查看结果。服务重启会读取原请求和完成记录；不能确认某一步是否已经执行时会暂停，不盲目重做。

制作中点击“人工设置”或“停止自动流程，改为人工设置”会停止自动后续步骤。已经提交的图片仍按原请求记录，返回后保留；取消后不会继续自动选图或导出。部分图片失败、结果未知、授权或配置变化时停止，不以缺图文档冒充全部完成。确认已提交任务结束后，可继续人工处理已有结果。

若画面描述准备失败，页面会明确说明尚未提交生图并保留分析方案。可进入人工设置检查简单描述后重新确认；程序不会自动重复整次制作。本地模型的英文生图字段使用结构约束，仍需通过语言、长度和图位校验才能提交。

本机智能体和图片 API 的新批准会把排除项一并冻结到实际发送的画面描述中；本地 ComfyUI 继续使用独立排除输入。图片中的文字、科学细节及事实准确性仍应人工检查，传递约束不等于保证模型完全遵守。

## 日间、夜间与跟随系统

工作台右上方有三档外观切换，设置页也提供相同入口。“跟随系统”按电脑本地时间自动切换：每天07:00起至19:00前为白色日间主题，其余时间为深色夜间主题。到点自动调整，休眠唤醒或回到页面时重新校准。选择日间或夜间后保持手动偏好，刷新后仍保留。浏览器禁止本地存储时，当前页面仍可以切换。首页继续保持电影式画面。

主题覆盖导入、方案、导演台、授权、选图、文档、连接设置和历史弹窗。首页继续使用原有电影式背景与文字配色，不随工作台切成白底。外观选择只保存显示偏好，不写入稿件、API密钥或生成参数。
