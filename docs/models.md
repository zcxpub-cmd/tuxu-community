# 模型配置

社区版不附带模型权重或密钥。文章分析与图片生成是两条不同的路线。

## 文章理解

当前通过本地 Ollama 阅读文章。先安装并启动 Ollama，再准备可按结构化 JSON 协议输出的模型；界面中的模型名称必须与本地一致。默认名称只是配置起点，不代表仓库已安装该模型。

分析输入包含导入的文章。默认连接本机模型服务；如果你自行把后端模型地址改为远程地址，文章也将发送至该地址，请自行核对数据范围与授权。

## 生图路线

| 路线 | 需要准备 | 使用边界 |
| --- | --- | --- |
| 豆包 / 火山方舟 | 自己账户的 HTTPS API 地址、可用模型或已授权 `ep` 接入点、密钥 | 支持图像 API 不代表账户已开通模型；模型列表不是生图权限证明 |
| GPT 兼容 API | 支持所需图像生成协议的 HTTPS 地址、模型标识、密钥 | 不是所有兼容聊天接口都支持图像生成；图像规格与参数依模型而异 |
| 本地 ComfyUI | 自己安装并运行的 ComfyUI、checkpoint 和所需标准节点 | 方框布局需要对应分区/蒙版节点，模型不一定遵守精确位置 |
| Codex 宿主协作 | 能使用内置生图工具、并能处理社区版请求桥的宿主会话 | 普通浏览器不会自动调用 ChatGPT 账户，也不能保证宿主提供某个特定模型版本 |

## 配置自己的 API

1. 在“云端生图 API 配置”中填写显示名称、HTTPS 地址、模型标识与密钥，启用并保存。
2. 点击“测试已保存配置”。这里只查询模型列表，不生成图片。
3. 如返回候选，可选择带入模型输入框，再手动保存。存在未保存修改时，测试按钮不可用。
4. 检查“配置”“连接与列表”“实际生图”三项状态。实际生成失败时，按页面中有限的中文诊断核对模型、接入点、账户或权限。
5. 在“授权与生成”选择该服务，确认当前画面描述与构图的外发范围后提交。

密钥保存后输入框清空；留空保留已有密钥，勾选“清除已保存密钥”才显式清除。更换 API 来源时需重新提供该来源的密钥，不应跨服务复用。

豆包路线使用界面说明的 2K 画幅；GPT 兼容路线可选择标准/高清，但实际支持依目标服务而定。本地与宿主生图质量取决于各自模型。应用不会因失败自动切换供应商或重新提交结果未知的请求。

## Codex 协作桥

选择 Codex 并提交后，任务进入等待协作状态。支持的宿主应读取待处理请求，成功领取对应冻结请求后才调用一次实际生图工具，并回填同一任务、作业、图位和授权标识对应的图片。仓库提供 `scripts/tuxu_cli.py` 的 `agent-requests`、`agent-claim`、`agent-result` 入口，具体参数可用 `--help` 查看。

CLI 与服务必须使用相同的 `TUXU_DATA_DIR`；否则领取与本机冻结请求无法对应。不要把完整生成文本、数据目录或领取后的文件上传到公开 Issue。取消会撤销尚未执行的协作；宿主不得对已领取或结果未知的请求反复重生。

该桥不包含第三方插件库，也不代替宿主工具的账户、权限或使用条款。没有支持的宿主时，使用自己的 API 或本地 ComfyUI。
