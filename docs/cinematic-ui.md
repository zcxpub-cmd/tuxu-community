# 电影式首页与统一工作台

首页主标题为两行：**让文字，拥有色彩。** 页面沿用黑洞方案的版式，提供黑洞、折光、星际、城市、田野、高山、大海与 DNA 共八个场景。

每次进入首页从随机袋中取一个场景，避免相邻重复；浏览当前首页时不切换场景。没有背景选择器。浏览器只保存场景 ID 与待用顺序，不保存稿件、提示词或密钥。

八个背景视频使用原生 Seedance 2.0 生成。先对无文字底图做轻度降噪并整理为 1280×720 首帧，再生成约 5 秒、720p、24fps 无声片段；网页版本做了首尾过渡，适合循环。标题、导航和按钮由 HTML 绘制，不包含在视频里。每次仅挂载当前场景的视频。视频出错时回退到底图；减少动态效果的系统设置和工作台“设置”中的动效开关均可改用静态背景。

工作台统一为深色阅读界面，覆盖文章导入、配图方案、简明导演台、授权生成、选图处理和文档导出。画风推荐仍可自由更改，专业项保持折叠。返回首页保留工作区的内存状态；切换任务或重新分析前保护未保存的修改。完成标记依据当前任务记录、真实候选图片和导出状态；历史导出不代表当前方案完成，零图方案用“无需此步骤”表达。

社区版的文章分析与提示词仍在本地模型执行。页面仅显示简明画面描述，生成图注继续使用“（AI 生成示意图）”。本次界面升级不更换已有模型、云端配置或稿件存储目录。

新增验证：

```sh
cd frontend
npm run test:scenes
npm run test:workflow
npm run build
```

发布检查仅允许 `frontend/public/visuals` 中已列明的 16 个媒体文件，并校验严格清单、哈希、大小及格式签名。此检查不替代播放器和视觉验收，也不保证任意未知凭据都能被模式扫描识别。
