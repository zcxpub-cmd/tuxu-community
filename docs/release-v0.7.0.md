# 图序社区版 v0.7.0 · 内置视觉导演与工作台修复

v0.7.0 把内置视觉导演、工作台外观和一键制作修复纳入社区版，并保留 v0.6.0 的十八套动态首页。

- **内置视觉导演**通过本地 Ollama 执行文章分析、提示词编写和可选的图片检查。检查默认关闭，开启后仅用于新授权。如果主体、数量、摆放、画风或文字要求不符或无法确认，一键流程会保留生成的图片并暂停，供你人工复核。 [设置和使用](builtin-agent.md)
- **工作台日夜外观**在“跟随系统”模式下按电脑本地时间切换。07:00 至 19:00 前使用浅色，其余时间使用深色。手动选择日间或夜间后保持所选外观。 [外观说明](one-click-appearance.md)
- **一键制作**给英文生图描述增加结构约束和有界纠正。准备失败时保留配图方案，并明确告知尚未提交生图。已提交但结果未知的请求暂停，方便人工确认。只填写标题、类型或风格后可以继续导入文件，新授权会把排除项一并传给使用单输入的生图服务。 [操作说明](one-click-appearance.md)
- **电影式首页**保留十八套动态场景，打开或返回时随机选景。v0.6.0 新增的十段视频在重播时经过首帧淡化衔接。 [场景列表](cinematic-ui.md) · [十景视频包](https://github.com/zcxpub-cmd/tuxu-community/releases/download/v0.6.0/tuxu-v0.6.0-homepage-motion.zip)

下载社区预览版源码，在仓库目录运行 `./setup.sh` 和 `./start.sh`。文章分析和提示词编写需要本机 Ollama，图片检查需要所选模型支持视觉输入。生图使用你配置的 ComfyUI、图片 API 或本机智能体。 [安装说明](installation.md)
