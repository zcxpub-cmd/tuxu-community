# 图序社区版 v0.1.0

把文章变成可审阅的配图方案，再把选中的画面插入文档。

图序是一个本地运行的开源文章配图工作台。你可以导入论文、新闻、小说或报告，检查建议图位，用简单导演台选择风格、明暗和物体摆放，确认后生成、选图并导出新文档。生成结果需要人工审阅。

**Tuxu Community** is a local-first, open-source article illustration workbench. Review image suggestions, adjust simple visual direction, approve generation with your own provider or a supported Codex host, then export an editable document. See the [short English introduction](docs/README.en.md).

## 已有功能

- 导入 DOCX、Markdown、TXT 或粘贴文字；本地 Ollama 分析文章并建议图位。
- 对照原文修改配图描述、段落位置、图注和比例；支持保存零图方案。
- 简单导演台：9 种风格选项、3 档明暗、可选背景、物体拖放与九宫格位置。相机、光线与精确数值默认折叠。
- 生图前明确确认服务、画面范围和尝试上限；修改方案后重新授权。
- 自带 API 密钥（BYOK）接入豆包/火山方舟或 GPT 兼容图像 API，也可使用本地 ComfyUI。
- 支持 Codex 宿主协作桥；需要宿主会话具备生图工具，独立网页不能调用 ChatGPT 账户。
- 候选图片人工选用，轻度中值降噪与 Lanczos 插值放大，导出 DOCX、Markdown 图片包和 HTML；不覆盖原稿。
- 本地任务记录、版本失效检查、未决请求恢复与云模型验证状态。

“候选模型可见”“API 配置完整”“实际生图成功”是不同状态。供应商权限、账户状态和输出效果以你的实际调用为准。社区版不附带密钥或模型权重。

## 快速开始

需要 Python 3.12+、Node.js 22.18+ 和 npm。支持 macOS/Linux。Windows 可在 WSL 的 Linux 环境中尝试运行；本版本不支持原生 Windows。全文分析需要一个已安装、运行的 Ollama 模型；本地生图模型是可选项。

从本仓库获取源码后，在仓库目录执行：

```bash
./setup.sh
./start.sh
```

打开 [http://127.0.0.1:8766](http://127.0.0.1:8766)。停止服务：

```bash
./stop.sh
```

应用使用独立的 `TuxuCommunity` 用户数据目录。需要自定义时，在启动前设置 `TUXU_DATA_DIR`；不要把密钥、稿件或数据库加入 Git。

完整步骤见[安装与运行](docs/installation.md)和[模型配置](docs/models.md)。

## 从文章到文档

1. 导入有权使用的文章，选择本地文章理解模型，开始分析。
2. 对照原文检查建议，修改或删除图位；不需要插图时可保存零图方案。
3. 进入导演台，选择风格、明暗和大致摆放，保存画面设置。
4. 选择已配置的生图路线，核对外发范围并确认授权，再提交生成。
5. 检查真实图片中的物体数量、文字、事实和构图，选用合适候选。
6. 检查插入预览、图注与编号，导出新文档，并在 Word/WPS 等阅读软件中复核分页。

更多操作见[使用说明](docs/user-guide.md)。

## 开源与私有边界

本仓库包含公开的通用分析/生图基础模板、简易视觉映射和工作流实现，采用 [Apache-2.0](LICENSE)。前端只展示简短画面描述，不直接显示完整生成文本；这属于界面与数据输出设计，不代表源码模板保密。

高级私有模板、私有策略、收费托管服务及其运营系统不包含在本仓库中，也不是运行社区版的前提。第三方模型、API、字体和素材各自适用其许可及服务条款。

## 当前局限

- AI 可能遗漏主体、增添物件、生成畸形或错误文字；风格和明暗是生成指导，物体方框不是像素级位置锁定。
- 科研与新闻画面应明确标注为生成示意，不能冒充实验结果、现场照片或证明材料。
- DOCX 导入与重建导出不承诺保留所有复杂排版、公式、修订、脚注、浮动对象或原分页；请保留原文件并人工复核。
- “降噪与放大”是传统图像处理，不是 AI 超分；不会修复缺失主体和事实错误。
- 当前以本机单用户使用为目标，不包含公网账户体系、多租户、计费或生产云部署。
- Codex 模式依赖受支持的宿主会话。没有该宿主时请选择 BYOK 或本地生图，提交等待请求不等于自动获得图片。

详细边界见[使用说明](docs/user-guide.md)和[安全说明](docs/security.md)。
