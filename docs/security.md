# 安全与数据

图序社区版 v0.1.0 面向本机单用户使用。它不是经过加固的公网多租户服务；请保留回环监听，不要直接将端口转发到公网。

## 数据边界

- 文章、任务记录、生成媒体、导出和 API 配置保存于用户数据目录。API 密钥存于本机后台配置，不回显给前端，也不保存到浏览器 storage。
- 全文分析会把文章发送给你配置的 Ollama 服务；默认是本机。自己设置远程模型地址会改变这一边界。
- 云生图在用户确认后发送当前画面描述与构图到所选服务；供应商有自己的数据处理规则。
- Codex 协作模式会将批准后的生成描述交由支持的宿主会话与其生图工具处理，需要该宿主及工具的相应权限。
- 通用基础模板随源码公开。前端不直接显示完整生成文本不能阻止本机管理者读取源码或自己数据，不构成源码资产保密机制。

不要在公开仓库、Issue、截图或日志中暴露密钥、完整稿件、个人资料、任务数据库、领取后的生成文件或带认证信息的 URL。分享前裁剪并脱敏，保留原稿离线备份。

## 应用中的保护

本地写接口检查 token 与来源，授权绑定原文、方案和模型；旧版本图片不能直接选入新方案。生成请求保留恢复标识，结果不确定时不自动重新提交。云模型列表与诊断使用有限公开投影，生成图片与导出中的媒体移除元数据。

这些措施有适用范围：本机 token 不是公网账户体系，后台文件权限不是操作系统管理员隔离，去元数据也不会修复生成画面的版权、事实或几何问题。

## 密钥与备份

使用自己的服务地址与对应密钥。更换来源时重新提供密钥，不将旧密钥发送到不相关服务。发现泄露时先在供应商处撤销或轮换，再更新应用配置；不要在公开 Issue 粘贴密钥求助。

备份数据目录前先停止服务。备份中可能包含稿件和凭据，应按敏感数据保管。自动化测试使用临时 `TUXU_DATA_DIR`，不要指向日常工作数据。

## 报告安全问题

若本仓库启用了 GitHub 私密漏洞报告，请使用仓库 Security 页的私密报告入口。若没有该入口，先提交一个不含利用细节和敏感数据的 Issue，请求维护者提供私密联络方式。不要猜测或使用文档未列出的邮箱。

私下报告时提供受影响版本、最小脱敏复现、预期与实际行为、影响范围和必要环境信息；不要发送真实密钥或完整数据库。涉及第三方供应商账户的问题，同时使用该供应商的正式支持渠道。

项目不承诺固定响应时限；修复状态以维护者在仓库中发布的信息为准。
