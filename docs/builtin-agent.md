# 图序内置视觉导演

图序在本机服务内管理文章导演、提示词编写、视觉检查三个角色。它们共用你选择的 Ollama 模型并依次执行；图片生成与文档导出继续使用已配置的工具。运行层不需要另装智能体框架，也不附带模型权重、账号或 API Key。

## 设置

进入工作台右上角“设置”，找到“图序内置视觉导演”：

1. 选择本地导演模型，默认 `qwen2.5vl:7b`。图片检查需要具备视觉输入能力的模型，普通文字模型不能替代。
2. 按需开启“生成后检查图片”，点击“保存导演设置”。新安装默认关闭，避免给旧任务增加调用；开启只对之后的新授权生效。
3. 在现有连接区域选择图片服务：本地 ComfyUI、自备云端图片 API 或具有生图能力的本机智能体。内置导演本身不提供图片算力或免费额度。

新文章使用已保存的模型；已有方案继续使用其分析时的模型。保存配置、模型服务可访问、真实图片检查成功是不同状态。检查开关不能证明所选模型实际支持看图。

## 一键与人工模式

一键模式仍在导入并保存文章后启动。开启图片检查的新授权会依次完成：文章分析 → 推荐画面及后台提示词 → 生图 → 逐张本地图片检查 → 选图 → 文档导出。

每篇最多5图、每图生成1次。检查对主体、数量、摆放、画风和图片文字分别返回“符合”“不符”或“无法确认”。五项齐全且全部符合后，自动流程才继续选图导出。任何不符、无法确认、模型不可用或执行中断都会保留图片并暂停，进入人工设置处理；不自动重画，也不以缺图导出冒充完成。

关闭检查的授权沿用原流程，界面明确说明尚未检查。人工模式中，可在当前有效图片卡片点击“检查这张图（本地）”，单独授权一次本地检查。检查本身不调用生图服务；每张图片在同一批准下只检查一次，重复点击、刷新或服务重启不重新请求。结果未确认时请人工查看，修改方案并重新授权后再制作。

修改建议采用固定的简短指引，例如核对主体、调整位置或画风。当前版本不直接用自然语言编辑原图；你可在导演台修改设置并重新授权生成。

## 模型与质量边界

文章分析和提示词沿用已有本地 Ollama 逻辑；图片检查将当前原图的受限缩略副本和用户可见画面要求发给本机 Ollama。原图保持不变，正式后台提示词、整篇原稿和云端凭据不进入视觉检查请求。

结构化模型调用使用 `temperature=0`、`num_ctx=8192`；图片检查输出上限为1000 token。结构格式不正确时最多增加一次本地格式修复；超时、传输失败、截断或执行结果未知不盲目重发。模型输入最长边1280像素，原图最多40MiB、约1600万像素，文件先校验哈希和可解码性。

本地视觉模型可能误判数量、位置或事实。“检查通过”只表示本次模型未发现明显差异，不能证明科学准确、像素锁定或正式出版质量。仍需人工核对。文本与视觉模型串行执行；与本地扩散模型共享内存时，实际等待时间取决于电脑配置。

## 恢复、隐私和版本

配置保存有版本检查；一键启动和新批准绑定当时的设置。运行中改变配置会暂停旧自动步骤，避免静默切换模型。检查记录绑定图片、图位、原图哈希、可见要求、批准和配置；相同像素的不同图位也分别检查。

取消立即阻止检查结果继续发表；已经生成的图像保留。服务重启遇到已记录但未确认的检查会标为中断，用户可以人工处理，不会推断它没有执行而重调。文件或方案变化使旧结果失效。

网页只显示固定类别结论和固定建议。完整提示词、检查内部绑定、原始模型正文和错误细节保留在后台边界之外，不写入公开响应或文档。本机管理员仍能读取自己的后台文件；商业私有策略应另放受控服务，开源社区模板不构成资产绝对保密。

## 开发接口

- `GET /api/builtin-agent`：无副作用读取模型、检查开关、角色、限额和配置 revision。
- `PUT /api/builtin-agent`：只接受 `model`、`visual_review_enabled`、`expected_revision`。需要有效本地访问校验，旧 revision 拒绝覆盖。
- `POST /api/tasks/{task_id}/assets/{asset_id}/review`：只接受 `{"confirm": true}`，异步返回任务；只检查当前已批准图片，不接受图片路径、URL、提示词或命令。
- 公共图片记录的可选 `visual_review` 含状态、五类固定检查、固定建议和模型名。状态为 queued、running、passed、needs_attention、unavailable、interrupted。

角色与工作流参考 [Awesome LLM Apps](https://github.com/Shubhamsaboo/awesome-llm-apps) 的本地推理、视觉规划流水线与执行门控设计。本实现复用图序自己的业务状态机，未复制或运行示例应用；示例中预设的信任分未用于画面质量判断。
