# 文章分析和提示词：模型参数与电脑配置

核对日期：2026-11-02。下列为当前社区版代码与开发机 Ollama 返回值，模型名可以在界面更换；安装包不包含权重。

| 项目 | 当前值 |
| --- | --- |
| 模型 | Qwen2.5-VL，Ollama 标签 `qwen2.5vl:7b` |
| 实际模型元数据 | 8,292,166,656 参数，约 8.29B；`7b` 是发布标签 |
| 格式/量化 | GGUF，`Q4_K_M` 混合 4-bit 量化 |
| 本机模型包大小 | 5,969,245,856 字节，约 5.97 GB / 5.56 GiB |
| 调用位置 | 本机 Ollama，默认 `http://127.0.0.1:11434/api/chat` |
| 实际上下文 | `num_ctx=8192`；模型元数据上限 128000，并未在图序中启用 |
| 单次输出上限 | `num_predict=6000`，不是每次必定输出 6000 token |
| 温度 | 分析、场景/物体/背景提示词使用 JSON Schema，`temperature=0`；通用纯 JSON 路径代码为 0.15 |
| 模型包默认温度 | 0.0001；被每次请求的上述温度覆盖 |
| 其他 | `stream=false`、`keep_alive=0`、请求超时 600 秒 |
| 分块 | 正文约 2000 字符/块，另有序列化长度控制；逐块覆盖后汇总 |
| 并发 | 本地模型操作串行；GPU 层数、线程数、KV 精度和 seed 未在图序中强制指定 |

`keep_alive=0` 是每次调用后卸载模型，目的是减少占用；多块长文会增加重复加载等待。温度为零也不意味着跨硬件和版本逐字确定。当前使用文字输入，虽有视觉能力，图序没有把文章中的图片发送给这个模型分析。

## 最低配置估算

只计算文章分析/提示词，采用当前 Q4_K_M、8K 上下文、单任务，不包含本地扩散生图模型和同时运行多个重型应用。下列是资源预算估算，未在各档机器做统一基准测试；不能用来保证延迟或并发。

| 路线 | 可用起点估算 | 日常使用建议 |
| --- | --- | --- |
| Apple Silicon Mac | M1 或更新，16 GB 统一内存，SSD 可用空间至少 15 GB | 24 GB 或以上，SSD 预留 25 GB；Pro 系列可改善等待 |
| Windows/Linux CPU | 较新的 4 核 CPU、16 GB RAM、SSD 预留 15 GB；可以无独显，等待较长 | 6–8 核、32 GB RAM；需要速度时加受 Ollama 支持的 GPU |
| NVIDIA GPU | 8 GB 显存 + 16 GB 系统内存作为尝试起点；8K 时可能部分卸载到 CPU | 12 GB 或以上显存 + 32 GB RAM 更稳妥 |

模型权重约 5.56 GiB；上下文缓存、计算缓冲和运行时还需额外内存。可先按模型运行部分约 7–10 GiB 留预算，再为系统、浏览器和图序留空间。因此不把 8 GB 总内存机器作为当前默认模型/上下文的推荐最低配置。显存不足时的 CPU 分担可能降低速度，不能将“能装载”当作全部 GPU 加速。

开发机当前实查是 Apple M3 Pro / 18 GiB 统一内存，已经有图序本地工作记录；这不代表其他档位的性能已经实测。若图片生成走智能体提供方的云工具，电脑不承担相应扩散模型显存；若智能体调用本地 ComfyUI/FLUX/SDXL，应另按生图模型增加预算。

Windows 上 Ollama 自身可用，但本版图序仍以 macOS/Linux 为支持范围，Windows 需使用 WSL 环境，不代表已完成原生 Windows 验收。
