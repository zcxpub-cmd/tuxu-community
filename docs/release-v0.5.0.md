# 图序社区版 v0.5.0 · 一键制作与日夜外观

导入文章后，可选择一键生成图文文档，也可继续使用人工设置。工作台新增日间、夜间、跟随系统三档外观，入口位于顶栏和设置页；电影式首页保持原有风格。

## 本版更新

- **一键图文制作**：新导入、尚未制作的文章，可一次确认本地文字模型、图片服务和导出格式。后台完成全文分析、语义画风推荐、图片生成、全部有效原图选用与文档导出，支持 Word、Markdown 图片包和 HTML。
- **明确执行范围**：每篇最多5张，每张仅尝试一次；出现失败、结果未知、配置变化或超出授权数量时停止。原稿只读，已有人工方案不被覆盖；可停止自动后续步骤并进入人工设置，保留已提交图片的结果。
- **持久化进度**：刷新页面不会重复提交；后台保存执行记录，服务重启后对无法确认是否执行的步骤暂停，不盲目重做。自动导出校验当前选图与原图完整性，旧导出不会冒充当前完成结果。
- **日间 / 夜间 / 跟随系统**：覆盖导入、配图方案、导演台、授权、选图、导出、连接设置和历史弹窗。默认跟随系统并实时响应变化，显示偏好只保存在本机。
- **沿用生图回填修复**：支持 Codex 原生工具返回的常见横向和纵向画幅并保留原图；确定校验失败明确结束，减少持续“待核查”和终态覆盖的问题。

## 运行与配置

需要 Python 3.12+、Node.js 22.18+、Ollama；支持 macOS/Linux，Windows 可使用 WSL 中的 Linux 环境。执行 `./setup.sh` 后 `./start.sh`，浏览器打开 `http://127.0.0.1:8766`。

社区版文章分析和生图提示词继续由本地 Ollama 生成，默认模型为 `qwen2.5vl:7b`。模型权重通过[官方模型入口](https://github.com/zcxpub-cmd/tuxu-community/blob/v0.5.0/docs/model-download.md)自行安装，不打入源码。Q4_K_M 量化包约6GB；文字分析的参考起点为 M1/16GB 或相近 CPU/16GB、SSD 预留15GB，建议24GB以上。这不是本地扩散生图的配置或速度承诺。

图片生成需自行连接具备生图能力的本机智能体、ComfyUI 或自备云端 API。原生智能体仍需兼容工具与自己的登录态；本机调用不等于离线或免费。仓库及源码包不携带维护者的本地配置、API Key、账号、私人稿件、任务数据或模型权重；新安装需要自行配置服务。

## 验证范围

本地已完成后台流程与竞态检查、前端主题及流程检查、构建和浏览器交互检查。隔离的模拟两图流程验证自动选图和真实文档引擎；另以自制短文完成本地 Qwen 分析、一次原生图片生成、自动选用与 DOCX 导出。真实单图文档已在 WPS 中打开，正文、整幅图片、图号及括号 AI 图注完整显示为1页，无重复独立声明。WPS有缺失字体提示，本页中文正常显示，不据此承诺字体完全一致。

这些证据不代表所有文章、模型、智能体或图片质量均已验收。生成内容仍需人工检查；复杂 DOCX 排版与分页可能改变。继续采用 Apache-2.0，第三方模型、API 和素材各按其许可与条款使用；本版仍为社区预览版。
