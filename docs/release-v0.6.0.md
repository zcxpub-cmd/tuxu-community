# 图序社区版 v0.6.0 · 十套新动态首页

新增市井、村庄、森林、湖泊、沙漠、金秋稻田、银河星野、生物细胞、微观分子和晨光花园。加上前版八套，首页现有十八个场景。 [场景列表与静图](cinematic-ui.md)

每次打开或返回首页时随机选景，相邻访问避免重复，同次访问保持同一场景。标题和操作按钮由网页绘制。每次只播放当前场景的视频。

新背景使用 Seedance 2.0 制作，生成前对无文字底图做了轻度降噪。随包视频为 1012 × 720、24 fps、5 秒、静音 MP4。网页在重播时经首帧静图淡化衔接。视频无法加载，或用户关闭界面动效时，首页显示对应的首帧静图。系统的减少动态效果设置同样适用。

下载社区预览版源码后，运行 `./setup.sh` 和 `./start.sh`，再打开本地工作台。首页直接播放随包素材。 [GitHub 发布页](https://github.com/zcxpub-cmd/tuxu-community/releases/tag/v0.6.0) · [安装说明](installation.md)
