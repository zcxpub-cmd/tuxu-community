# 贡献指南

欢迎修复缺陷、改善安装体验、文档、可访问性和模型适配。先阅读[开发说明](development.md)与[安全说明](security.md)。

## 提交问题

普通缺陷请在本仓库的 Issue 中提供：版本、操作系统、可复现步骤、预期行为、实际行为，以及脱敏后的必要错误信息。优先使用自制短文，去掉 API 密钥、真实稿件、姓名、后台路径、任务数据库和完整生成文本。

UI 问题可提供裁剪后的截图；说明浏览器宽度和所处步骤。模型效果问题请注明模型、生成路线与是否真实调用，避免把某一张成功图当成所有风格或位置控制的保证。

疑似漏洞不要公开利用细节，按[安全报告方式](security.md#报告安全问题)处理。

## 提交修改

1. Fork 本仓库，在独立分支上修改。
2. 使用独立测试数据目录，只修改与问题直接相关的代码和文档。
3. 运行相关检查，并写明测试范围；涉及界面、图片或导出时补充实际显示验证。
4. 提交 Pull Request，描述问题、修改后的行为、验证证据和仍存在的限制。

不要提交密钥、真实任务、下载模型、`node_modules`、虚拟环境、生成导出、个人路径或第三方插件库。新增依赖须说明用途和许可；新增生图请求或不确定结果重试必须保持明确授权与幂等规则。

## 代码与素材

中文优先编写面向用户的文档，代码使用清晰的英文命名。保留简单导演台；新专业设置优先折叠，避免让用户编辑完整生成文本。

请确认你有权以本仓库的 Apache-2.0 许可提供贡献。外部来源、第三方依赖和素材需注明来源与相应许可；不因项目开源而自动获得其他模型、插件或图片的权利。

## 评审

评审重点包括：授权与恢复是否可靠、数据是否泄露、跨配置响应是否错位、导出是否保持原稿、用户是否能理解真实状态。CI、Mock、实际 API 结果和用户接受是不同证据，请准确标注。
